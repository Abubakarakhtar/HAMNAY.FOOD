HAM-NAY FOODS — Ready-to-deploy static website

FILES
- index.html: complete responsive menu, cart, price calculations, and WhatsApp order flow
- vercel.json: simple Vercel configuration

DEPLOY TO VERCEL
1. Extract this ZIP on your computer.
2. Put the files in a GitHub repository (index.html and vercel.json in the repository root).
3. Sign in at https://vercel.com and choose Add New -> Project.
4. Import the repository and click Deploy. No build command is required for this static HTML site.
5. Open the generated .vercel.app URL.

MENU / CONTACT
The menu prices and all three phone numbers are included from the supplied poster.
WhatsApp checkout opens a prefilled message to 0300 4583050 (+92 300 4583050).
Images are loaded from Unsplash over the internet, so the menu photos need an internet connection.
This is a static frontend: it does not store orders in a database or provide a private admin panel.
